# Phase One Implementation Plan

**Goal:** 准备独立 Dify 源码与可测试的 Mock FastAPI 骨架。
**Architecture:** 官方源码在 ECS /opt/dify；自研代码单独管理，连接方式待实际网络核实。
**Tech Stack:** Dify, FastAPI, Pydantic, pytest, Docker Compose；DeepSeek 本阶段禁用。

1. 只读检查路径、Git、SSH 别名；没有连接时明确阻塞，不猜测。
2. 查官方正式 Release 和标签 commit；有连接才检查资源与 /opt/dify 并安全克隆。
3. 创建严格的 question/answer/evidence 输入契约，空白、缺字段、超长和未知字段返回 422。
4. 先编写接口及禁止外网访问测试，再实现只返回 not_evaluated 的 Mock。
5. 执行 python -m pytest -q service/tests，检查文件及约束，记录已验证与未验证项。
6. 不提交、不推送、不启动部署，交用户审核。

无需新 worktree：当前目录无 .git，无法创建；不得自行构造远程配置。
